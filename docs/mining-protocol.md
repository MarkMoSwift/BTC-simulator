# 数据格式与接口约定

本项目为课堂模拟器。金额以聪为整数单位，交易需由对应钱包签名；服务端验证交易及工作量。

## 区块头

区块头为 84 字节，字段依次为 version（4）、prev_hash（32）、merkle_root（32）、timestamp（4）、difficulty（4）、miner_tag（4）、nonce（4）。整数使用 uint32 小端序，哈希字段为十六进制解码后的字节。

区块哈希为 SHA-256 的两次运算结果，按大端整数与目标值比较。

## 作业与结果

作业包含 job_id、区块头字段、share_bits、share_target 和 block_target。目标值使用 64 位十六进制表示。份额包含 job_id、nonce、share_bits；nonce 范围为 0 到 4294967295。

结果包含 accepted、reason、work、next_share_bits；可能携带 block 或新 job。结果应绑定实际计算时的作业及难度。重复或过期作业、无效哈希及超限提交会被拒绝。

## 钱包与交易

签名使用 P-256，公钥为 64 字节 x || y，签名为 64 字节 r || s。地址为 sim 加公钥 SHA-256 前 20 字节的十六进制。

交易的规范 JSON 按键排序、无空格、非 ASCII 转义。不得向他人提供私钥；清除浏览器数据可能丢失钱包。

## 公平性

3.x 场次由各节点独立验证区块与交易。有效主链区块的出块钱包获得 50 币基础奖励及该块手续费。工作量样本用于当前节点的算力观测，余额和累计奖励按主链重放。重组后确认数、余额与藏品状态更新。

3.x 区块头 version 为 3。普通交易额外包含 domain 字段，其值为场次创世哈希，参与规范编码、交易号和签名。节点间握手核对协议大版本、网络、场次和创世身份。不同大版本之间的链不兼容，同一大版本的应用更新延续既有共识规则。
